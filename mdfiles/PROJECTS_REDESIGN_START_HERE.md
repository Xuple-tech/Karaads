## 📞 Support & Help

### If Something's Wrong
1. **Check logs**: `storage/logs/laravel.log`
2. **Check console**: F12 in browser
3. **Clear cache**: `php artisan cache:clear`
4. **Hard refresh**: Ctrl+Shift+R
5. **Read docs**: Check documentation files

### Common Issues & Fixes
- Routes not found → `php artisan route:clear`
- Styles not updating → `npm run dev` restart
- Service error → Check file location
- Database error → Run `php artisan migrate`
